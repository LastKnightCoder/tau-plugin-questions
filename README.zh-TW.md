# 問題管理

讀書、寫作、和 AI 對話時冒出來的疑問，先記下來，再慢慢弄明白。

## 能做什麼

- **記下問題**：在問題頁頂部的輸入框裡記下，寫「#分組」直接歸入那個分組。
- **按分組整理**：問題分組顯示在側邊欄，把問題拖到分組上即可移動。
- **掛上材料**：把相關的卡片、文章、專案文件、白板、劃線、PDF 標註、剪藏和對話掛到問題下面；也可以直接從問題裡新增一篇文章或一張卡片。
- **記錄探究過程**：每次掛上材料、改狀態都會記進軌跡，也可以隨手「記一筆」。
- **寫下答案**：在問題下寫獨立答案，也可以把它變成卡片、文章或專案文件，在哪裡改都同步。
- **繼續深入**：圍繞問題發起對話，或者把問題立項為 Notebook。

首頁的「探究中的問題」面板列出最近有進展的問題。

## 開始使用

1. 在外掛中心安裝並啟用「問題管理」。
2. 點側邊欄的「問題管理」，新增第一個問題。

## 常見問題

**問題會同步嗎？** 會。問題、分組、答案和軌跡都存在資料庫裡，隨資料庫一起同步。

**停用外掛後資料還在嗎？** 在。重新啟用後照常顯示；解除安裝後保留 7 天，期間重新安裝即可還原。
